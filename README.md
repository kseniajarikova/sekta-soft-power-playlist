# SOFT POWER · музыка для движения

Одностраничный интерактивный лидмагнит для соцсетей и воронок #sekta.

## Что внутри

- фильтры по кардио, силовой/функциональной тренировке и танцам;
- поиск по трекам и исполнителям;
- сохранение избранного в локальном браузере;
- копирование списка сохранённых треков;
- поиск каждой композиции в Яндекс Музыке и Spotify;
- кнопка перехода в каталог онлайн-курсов #sekta.

Ссылки на музыкальные сервисы ведут на поиск по точному названию и исполнителю, чтобы можно было выбрать доступную версию трека.

## GitHub Pages

Сайт статический и не требует сборки. Для публикации выбери в настройках репозитория **Pages → Deploy from a branch → main → /(root)**. Главная страница — `index.html`.
